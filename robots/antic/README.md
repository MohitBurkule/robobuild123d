# AntiC

150 g antweight pneumatic flipper built in `build123d` from reference photos.

## Reference Images

- `reference/antic_ref.png` — external 3/4 view (black textured flipper plate, pink anodized wedge tip, translucent UHMW front skirt, green-titanium side rails, 4WD ribbed wheels, blue hex fitting)
- `reference/antic_internals_1.png` & `reference/antic_internals_2.png` — white prototype showing internal twin flipper arms, forward-angled pneumatic ram, transverse buffer tank, and central spur-gear 4WD linkage.
